# Raphaels Kochbuch

Offline-Web-App mit Raphaels Rezeptsammlung (Portionenrechner, Timer, Einkaufsliste, PDF).
Die Rezepte in `rezepte.enc.json` sind verschlüsselt; zum Öffnen braucht es das Passwort.

Installation auf dem Handy: Seite in Chrome (Android) bzw. Safari (iPhone) öffnen und «App installieren» / «Zum Home-Bildschirm» wählen.
